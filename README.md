# CodePilot — веб-агент для программирования

Минимальный запускаемый starter-проект в стиле Claude Code: чат с Claude API, файловое дерево, просмотр/редактирование файлов, предложения изменений с ручным подтверждением и ограниченный терминал.

## Возможности

- Flask backend + простой адаптивный интерфейс.
- Выбор провайдера и модели в веб-интерфейсе: Anthropic Claude API или OpenAI/OpenAI-compatible API. API-ключ вводится в настройках модели.
- Файлы доступны только внутри `WORKSPACE_DIR` (проверяется разрешённый путь).
- Изменения от ИИ применяются только после нажатия «Применить все изменения».
- Терминал без `shell=True`, с allowlist команд, таймаутом и ограниченным выводом.
- Docker Compose публикует порт только на `127.0.0.1`.

## Запуск на Linux/VPS

```bash
unzip codepilot.zip
cd claude_code_web
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python app.py
```

Открой `http://127.0.0.1:8000` на самом сервере. Нажми «Модель / API», выбери провайдера, укажи название модели и вставь свой API-ключ.

Для удалённого доступа используй Nginx/Caddy с HTTPS и обязательной аутентификацией (например, VPN или OAuth Access). Не выставляй приложение напрямую в интернет: в starter-версии нет пользовательской авторизации и CSRF-защиты.

## Docker

В `requirements.txt` добавь `gunicorn>=22,<24` для запуска Dockerfile, затем:

```bash
cp .env.example .env
# отредактируй .env и добавь API-ключ
docker compose up --build -d
```

Открой сервис через защищённый reverse proxy на сервере. Порт контейнера привязан к localhost.

## Важные ограничения безопасности

Это стартовая реализация, а не полная изоляция уровня Claude Code. Allowlist команд уменьшает риск, но не заменяет контейнерную/OS-песочницу: например, некоторые разрешённые инструменты могут запускать дочерние процессы или читать доступные процессу файлы. Запускай от отдельного непривилегированного пользователя, держи рабочую папку отдельно, добавь авторизацию, HTTPS, CSRF-защиту, аудит действий и более строгую sandbox-среду перед использованием с недоверенными пользователями.

Ключ вводится в веб-интерфейсе и не сохраняется приложением на диск, но отправляется серверу для вызова API. Используй только свой доверенный сервер, добавь авторизацию и HTTPS; не вводи ключ на чужом экземпляре.
